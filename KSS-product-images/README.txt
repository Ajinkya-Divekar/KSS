KSS Bharat product images

png/  transparent cutouts (full quality)
svg/  SVG files that contain the same cutout image, so they scale and sit on any background.
      Each also has an invisible path with id="outline" tracing the product shape (usable as a clip path or cut line).

Note: these are photo cutouts, so the SVGs are not true vector art. Real vector artwork would need a redraw.
